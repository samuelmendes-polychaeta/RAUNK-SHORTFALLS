This repository contains the dataset for the review project "The marine annelid trait manifesto: A call to rethink functional traits for ecological and conservation research"

The repository is organized in three folders

Data:
- Database with all analyzed papers (data.xlsx)
- Scopus bibtext file (SCOPUS_Apr_9_26.bib)
- Web of Science bibtext file (WOS_Apr_9_26.bib)
- Bibtext of the two databases merged (final_base_bbmetrix.rds)
- Standardized keywords for the bibliometric analysis (keywords_STANDARDIZED.xlsx)

scripts:
- R scripts for bibliometric data preparation, and for the review analyses

figures
- Main figures generated from R studio and the corel draw plates
